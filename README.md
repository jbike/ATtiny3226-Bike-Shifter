# ATtiny3226-Bike-Shifter
Use a modified servo to shift bicycle gears electronically.

Uses a single 18650 battery, MG966R servo modified.

Added AS5600 rotary hall sensor feedback, DRV8833 motor driver.

Configured for deep sleep between shifts, 0.7uA, shifts remain fast.

3D printed servo bracket. Uses a standard rear derailleur with spring removed.
